**The Peppol validation layer is real now — and the credit-note path carries a credit note.** Pre-P34, the SALES_CREDIT_NOTE InvoiceNow thread was triply broken (a hollow document, the wrong validator, an artefact XSD) — and the discovery proved the INVOICE path equally broken at the validation layer: every generated document, either type, failed its own schema, so no real transmission could ever have succeeded. The ISO-4217 vocabulary closes the input side: the five currency inputs share the active-code allowlist, so the P33 currency-truth surfaces can no longer be fed a typo.
