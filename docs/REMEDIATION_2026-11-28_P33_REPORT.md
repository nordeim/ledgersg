## 3. The closure verdict (the headline)

**Every money-denominated response now owes its currency the same truth as its amounts.** The Peppol generator no longer hardcodes `currencyID="SGD"` on the 11 amount elements — the document's own currency threads from the mapper to every amount (a USD invoice now transmits UBL whose header and amounts agree; `TaxCurrencyCode` stays SGD by the documented statutory decision). The three financial reports carry the org's `base_currency` (the ledger's denomination), and the account balance carries the account's own currency (the TODO retired). All byte-identical on the SGD default substrate — the live re-verification proved it — and pinned by 11 new gates whose fixtures sit at the NON-default value (the lesson: a fixture at the default value can never distinguish "the code reads the value" from "the code hardcodes the default").
