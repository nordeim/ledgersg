## 3. The state-machine verdict (the headline)

**A pagination click can no longer be silently lost, on any surface, for any reason in this class.** The P26 sprint wired every list surface to page server-side — and its offset-reset placement (batched into the debounce tick, fixing the P26 double-fire) left a mount-run landmine: the effect's first run fired `setOffset(0)` ~300ms after mount (~600ms under StrictMode), and any page change inside that window silently reverted to the cached page 1 — no refetch, no feedback, invisible to the mocked-hook tests (a module mock cannot exhibit cache behaviour) and to URL-counting assertions (no refetch happens — that IS the bug). Only the serial full-run e2e caught it, and only sometimes-by-timing — the isolated run passed. This sprint closes the class: the page restart now belongs to the VALUE CHANGE (a real search edit), the ORG IDENTITY (a switch), or the FILTER IDENTITY (a narrowing) — never to a timer's mount-run — and each contract is pinned per surface by a real-hook transport-URL spec. The full-run e2e is green deterministically, the fresh-DB first-run proof holds (43/43, 0 skipped), and the capture 169 shows the page-2 state held 1.5s past the old race window.
